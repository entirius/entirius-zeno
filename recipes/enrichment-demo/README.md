The module set of the oohlala test env without the client's code, for working on enrichment and the AI studio on
test data: shop without the Magento, BaseLinker, GetResponse and crypt modules and without the B2B ones (leads,
communicator, siteintel, regon_api). Catalog, prices, stock, content, checkout and the storefront stay, with both
frontends. Pair it with the CMS release candidate oohlala runs (`CMS_BRANCH=v3.3.0-rc.5`); how to start it and point
it at a toolbox: [RUN.md](RUN.md).
